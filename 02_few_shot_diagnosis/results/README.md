# 冻结研究结果与上传检查

- `rcsd_v1/`：原始对照结果，保留元学习原型、普通迁移、从头CNN、RF及消融。
- `rcsd_v2/`：432行神经单模型/集成指标、38,016条逐窗预测、计划、角色和日志。
- `unsuccessful_trials/`：源增强和目标支持增强的完整条件指标、选参记录及摘要；未采用为默认部署方案。
- `verification/`：历史重训证据、结果表审计及2026-10-27上传相关回归和算子检查。

所有记录对应受控半合成研究，不是现场真实故障诊断效果。`completion.json` 等保留实验冻结时的状态，例如 `remote_pushed=false` 表示当时尚未推送，不用于判断当前GitHub分支是否存在。当前交接状态见[测试报告](../../docs/凌晨/测试报告.md)及合并请求。

此目录没有传感器原值；逐窗预测中的背景/窗口ID用于追溯，不能计为独立机械故障事件。重新运行实验写入Git忽略的 `outputs/`，不覆盖这些冻结结果。
