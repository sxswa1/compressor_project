# 压缩机跨工况故障泛化诊断算法 —— 代码说明

> 任务：算法设计——压缩机跨工况故障泛化诊断技术（负责人：李佳耀）
> 交付物：算法代码 + 代码说明（满足算子集成要求）+ 技术报告 + 测试报告

## 1. 总体说明

本算法实现旋转机械（压缩机/轴承）跨工况故障泛化诊断：在若干源工况（不同负荷/转速）
的有标签数据上训练，在**未见过的目标工况**上完成 ≥8 类故障识别，验收要求跨工况
泛化精度 ≥80%。

代码按《压缩机项目算法开发分工与实施方案》第四部分目录结构组织，两条线交付、互为补充：

| 交付形态 | 位置 | 用途 |
|---|---|---|
| 公共算法库 | `common_algorithms/` | 可复用通用实现（工况识别 + 5 类信号特征），供其他研究直接调用 |
| 研究子项目 | `03_cross_condition/` | 跨工况泛化诊断完整流程（数据/模型/训练/评估/脚本/测试） |
| 算子封装 | `dataflow_operators/` | 符合 DataFlow 算子规范的自包含单文件，供平台注册执行 |

三者算法一致：`dataflow_operators/` 下的算子是把对应算法的核心逻辑收敛为
**单个自包含 `.py` 文件**，满足「不依赖本地脚本/绝对路径/Notebook 状态」的算子接入要求。

## 3. 核心算法

### 3.1 数据组织与预处理

- **数据**：CWRU 轴承公开数据集，10 类（正常 + 内圈/滚动体/外圈故障 × 0.007/0.014/0.021 in），
  4 种负荷 0/1/2/3 HP（对应转速 1797/1772/1750/1730 RPM）作为 4 个"工况（域）"。
- **切片**：滑窗长度 1024 点、重叠率 0.5，将长信号切成样本矩阵 `(n, 1024)`。
- **归一化**：逐样本 z-score（每条样本独立归一，避免信息泄露）。
- **跨工况协议**：源工况训练、目标工况测试（如 {0,1,2}→{3}），或留一工况交叉验证。

### 3.2 工况识别（`common_algorithms/data_processing/operating_condition.py`）

规则版工况识别采用「负荷标签 + 转速换算 + 频谱转频估计」：工况（域）= 电机负荷档位
0/1/2/3 HP，对应转速 1797/1772/1750/1730 RPM。判定优先级：给定转速 rpm >
给定工况档位 domain > 从信号频谱（26–32 Hz 频带）估计转频后按最近转速映射。
据此对长信号切片并标注工况，构建跨工况测试样本。

### 3.3 信号特征提取（`common_algorithms/feature_extraction/`）

| 特征 | 维度 | 说明 |
|---|---|---|
| 时域 | 13 | 均值、标准差、RMS、峰值、峰峰值、绝对均值、能量、峰值因子、波形因子、脉冲因子、裕度因子、峭度、偏度 |
| 频域 | 7 | 谱质心、谱扩散、低/中/高频带能量占比、谱峰频率与幅值 |
| 包络谱 | 3 | Hilbert 包络谱的质心、峰值频率、峰值幅值（关注 0~500Hz 故障频带） |
| 小波 | 5 | db4 小波 4 层分解子带能量占比 |
| EMD | 4 | 各 IMF 能量占比（PyEMD 缺失时输出全零特征并降级） |

### 3.4 物理机理模型（`03_cross_condition/models/feature_alignment.py`）

利用轴承故障特征频率与转速成正比（BPFI=5.415×fr、BPFO=3.585×fr、BSF=2.357×fr、
FTF=0.398×fr），把包络谱转换到**阶次域**（频率/转频），在各故障阶次及其谐波处提取
归一化谱幅值。阶次域特征对负荷/转速变化相对稳定，据此构建占优故障阶次的规则诊断，
并对转速波动做 ±5% 容差。

### 3.5 深度学习模型（`03_cross_condition/models/`）

- **骨干网络**（均输出 256 维特征）：
  - `CNN1D`：三层一维卷积 + 全局平均池化。
  - `WDCNN`：宽核（64）第一层卷积，旋转机械故障诊断经典结构。
  - `ResNet1D`：带残差连接的一维 ResNet。
  - `LSTMNet`：CNN-LSTM（宽核卷积压缩长序列 → 双向 LSTM 时序建模）。
- **域自适应（核心创新）**：在骨干 + 分类头之上，用目标工况**无标签**数据对齐分布：
  - `DANN`：梯度反转层（GRL）实现对抗域自适应，α 按 `2/(1+exp(-10p))-1` 退火。
  - `DeepCORAL`：对齐源/目标特征协方差二阶统计量。
  - `DAN`：多核（5 核高斯）MMD 对齐源/目标特征分布。

### 3.6 传统机器学习基线（`03_cross_condition/models/traditional.py`）

在手工特征（时域/频域/包络谱/小波/EMD/阶次域）上训练随机森林与梯度提升，作为
跨工况诊断的对照方法。

### 3.7 模型切换（算子集成）

`03_cross_condition/models/domain_adaptation.py` 的 `create_model(name, num_classes)`
按名称切换模型，共注册 16 个深度学习模型名（`src_/dann_/coral_/dan_ ×
{cnn1d, wdcnn, resnet1d, lstm}`），加上 `random_forest`、`gradient_boosting`、
`physics_rule`。满足「多模型 + 模型切换 + 算子集成」要求。

## 4. 算子封装（`dataflow_operators/`）

每个算子为**单个自包含 UTF-8 `.py` 文件**：完整 `import`（仅标准库/三方库）+
算法实现 + 标准入口 `execute(df, ...)`，无顶层副作用、无绝对路径依赖、
无本地项目文件依赖。共交付 7 个算子：

| 算子 | 入口 | 输出端口 |
|---|---|---|
| `data_processing/operating_condition.py` | `execute(df, rpm_col=, domain_col=, sample_rate=, window_len=, overlap=)` | `out_1` 逐片段工况识别；`out_2` 工况分布统计 |
| `feature_extraction/time_domain.py` | `execute(df, signal_col=, window_len=, overlap=)` | `out_1` 13 维时域特征表 |
| `feature_extraction/frequency_domain.py` | `execute(df, signal_col=, sample_rate=, window_len=, overlap=)` | `out_1` 7 维频域特征表 |
| `feature_extraction/envelope_spectrum.py` | `execute(df, signal_col=, sample_rate=, window_len=, overlap=)` | `out_1` 3 维包络谱特征表 |
| `feature_extraction/wavelet.py` | `execute(df, signal_col=, wavelet=, level=, window_len=, overlap=)` | `out_1` 5 维小波特征表 |
| `feature_extraction/emd.py` | `execute(df, signal_col=, n_imfs=, window_len=, overlap=)` | `out_1` 4 维 EMD 特征表 |
| `fault_diagnosis/cross_condition_diagnosis.py` | `execute(df, mode=, model_name=, checkpoint=, sample_rate=, window_len=, overlap=)` | `out_1` 逐切片诊断；`out_2` 类别统计 |

### 4.1 标准入口契约（诊断算子）

```python
def execute(df: pd.DataFrame, mode="deep", model_name="src_wdcnn",
            checkpoint="", sample_rate=12000, window_len=1024, overlap=0.5,
            signal_col="signal", rpm_col="rpm", **kwargs) -> dict[str, pd.DataFrame]
```

- **输入表 `df`**：振动信号表（`signal` 列存采样点序列，可选 `rpm` 转速列）。
- **`mode`**：`deep`（深度学习，需训练产出的 `checkpoint.pt`）或 `physics`
  （物理机理规则，免权重，阶次域包络谱判别）。
- **`model_name`**：`src_/dann_/coral_/dan_ × {cnn1d, wdcnn, resnet1d, lstm}`，按名切换。

### 4.2 输出端口（诊断算子）

| 端口 | 变量 | 列结构 |
|---|---|---|
| `out_1` | 逐切片诊断结果 | sample_id, pred_class, class_name, confidence, rpm, model |
| `out_2` | 类别统计 | class_name, count, ratio, model |

每个端口对应一个 `pd.DataFrame`（非 CSV 路径、非打印文本）。空输入或数据不足返回
具有明确列结构的空表 / 状态表。

## 5. 运行方式

```bash
# 1. 训练：源工况 0/1/2 -> 目标工况 3，并保存权重
python 03_cross_condition/scripts/train.py --model src_wdcnn --source 0 1 2 --target 3 --save-model

# 2. 域自适应模型
python 03_cross_condition/scripts/train.py --model dann_wdcnn --source 0 1 2 --target 3

# 3. 留一工况交叉验证（跨工况泛化验收指标）
python 03_cross_condition/scripts/train.py --model src_wdcnn --protocol leave_one_out --save-model

# 4. 评估 / 9 种方法横向对比（生成对比表，供测试报告）
python 03_cross_condition/scripts/evaluate.py
python 03_cross_condition/scripts/compare.py --source 0 1 2 --target 3

# 5. 冒烟测试
python 03_cross_condition/tests/test_features.py
python 03_cross_condition/tests/test_operating_condition.py
python 03_cross_condition/tests/test_models.py
```

## 7. 关键设计说明

1. **跨工况泛化**：核心是阶次域物理特征（对转速恒定）+ 域自适应（DANN/CORAL/MMD
   对齐源/目标分布），二者共同保证模型在未见工况上的稳定性。
2. **避免数据泄露**：逐样本归一化（不跨样本）、源/目标工况严格隔离、目标工况数据
   仅在测试时使用（域自适应仅用其无标签信号对齐分布，标签不参与训练）。
3. **可复现**：固定随机种子（`seed=42`），训练/评估流程可重复；权重与指标
   落到 `03_cross_condition/outputs/`。
4. **算子自包含**：`dataflow_operators/` 下每个 `.py` 均不 `import` 本地项目文件，
   源码整体可作为平台 on_run 脚本直接注册执行。
