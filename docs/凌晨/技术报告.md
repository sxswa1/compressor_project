# RCSD小样本诊断优化技术报告

2026-10-26，凌晨。研究输入及标签沿用首版。所有目标结果是既有查询被查看后的优化探索。

## 最终方法

源监督CNN250步、背景全局分离的ProtoNet350任务；每次目标适配250步，学习率0.002，种子42/43/44，目标支持抽样11/22/33，K1/5/10。源期与目标为相同已知四状态，未实现真实跨数据集迁移或未知类别识别。

各集成包含三个相同结构、不同训练种子的模型，使用相同目标支持。Softmax输出等权平均，非多数硬投票，未对查询拟合权重。评分没有校准为真实故障概率。训练和推理神经开销约三倍；是否值得由使用场景决定。

最终研究432行指标、38,016条逐窗预测、36份神经资源；交付另复用3份RF，共39份资源。单模型27份、集成9份、RF3份。规范输入25通道×20点、900秒；同一个物理输入契约同时约束名称、单位、物理量、聚合和时钟。

## 背景配对收益及不确定性

先对同一支持抽样下三个单模型的正确性取平均，与对应集成正确性相减；再在同一背景内平均四状态和三个支持抽样，按22个背景重抽20,000次。以下单位为百分点，区间只描述固定种子集合、这22个受控背景的不确定性。非重叠背景之间也可能存在时间相关，因此这是探索性近似区间。它不覆盖新设备、真实故障、生成规则或优化尝试的选择偏差，不作为独立确认性显著性结论。

## 源期验证与数据生成边界

前推三折：训练前10背景验证10—19；训练前18验证18—30；训练前23验证23—30（索引从0起）。每折验证池中五背景供支持，其余作查询；K1/5，支持抽样11/22，主/半幅度两种验证响应。每个源编码器均重新训练，归一化只拟合折内训练背景。元学习任务采样逐任务检查原背景跨类别角色互斥。

构造规则与幅度估计在首版已用前半年整体固定，因此这里的源期分折不是对生成规则与幅度估计的完全嵌套验证。最终9—12月幅度参数仍仅来自1—6月，未使用查询估计。集成权重固定，不由这轮验证成绩或目标查询调节。

四个查询版本复用22个背景，352条记录中未注入对照按场景重复。全520窗含源124、支持44、四版查询352；它们不是520次独立故障。原始RCSD无自然故障标签，未注入候选也未获健康确认。

## 未采用的两轮优化

第一轮：源成对强度增强310行但仅31背景/124原标签；3折×2种子源内选择统计/原始神经表示的欧氏、类内对角或收缩协方差距离，以及保留源分类头的微调策略。完成696行目标指标和61,248条预测，22份固定资源，效果不支持替换基线。

第二轮：前推源验证选择原支持、三档或五档目标支持增强，分别为RF/CNN/迁移/元学习选择。完成720行指标、63,360条预测和24份资源。K5增强后元学习87.12%/73.48%，CNN86.74%/71.46%，迁移80.81%/67.05%；均低于原支持对照。未将未采用模型作为最终默认资源。

目标成对增强仅在当前半合成配对支持上成立，实际故障不能假定有对应健康反事实。预测从未使用查询的配对原样。源增强与目标增强失败的完整配置、选择记录、逐窗输出和权重保留在各自输出目录，交付包附摘要、全部指标与源码。

## 复现与交接

独立目录下的39份资源已重放，13,728条预测标签及评分与实验导出一致；39次空输入、39次不兼容采样契约检查通过。另行切换迁移集成的88窗命令行调用通过。默认演示固定支持抽样11，元学习集成主场景89.77%，区别于三次支持抽样平均的90.53%。
