# 数据来源、划分与复现

## 数据与贡献

公开来源：[Refinery Compressor Sensor Data, One-Year Dataset](https://zenodo.org/records/14866092)，DOI 10.5281/zenodo.14866092。作者：Aristotelis Ntafalias、Savvidis Chrysovalantis、Pantelis Lamprinoudakis、Alkis Kitsatoglou；2025年发布。2022年压缩机DCS记录，25测点、35,036行。

原文件 `Centrifugal compressor _2022.xlsx` 的SHA256：

```text
384565606d78f857655ac01bc4b006a31ae9d095a00472e031a9f82070715e62
```

原始工作簿及派生测点数值不随此Git提交分发；使用者自行取得并遵循来源使用条件。本仓保留构造规则、模型、指标、预测、划分和审计记录。现场数据、微信附件、合同和管理文件均未上传。

背景筛选和三组响应规则参考高淏宇提交 [f731289](https://github.com/sxswa1/compressor_project/tree/f731289a76e8d266a82e3672ee5586e8505150bc/01_early_warning)，保留其贡献。本方向新增诊断角色划分、RF/CNN、任务式元学习、迁移、集成、消融及封装验证。

## 评价边界

4状态：未注入候选、温度组模拟异常、油压与温度组模拟异常、振动与轴位移组模拟异常。未注入不等于获认证健康，3种注入不等于经确认的机械故障机理。没有真实故障真值，不宣称现场精度或8类覆盖。

整背景480点约120小时，源31背景、支持池11背景、查询22背景互斥。窗口20点，首末点4.75小时。源124标签；目标每类K=1/5/10时4/20/40标签，分别来自1/5/10背景。各对照共用源归一化器。支持抽样11/22/33，神经种子42/43/44。

同一机组跨时段适配不是真正跨数据集验证。目标查询曾被查看，相关优化是探索性。压力场景复用背景，不增加事件数；失败增强保留，不挑最优条件替代完整结果。

## 复核现有模型

安装本方向requirements后，在仓库根目录运行：

```text
python 02_few_shot_diagnosis/scripts/restore_rcsd_inputs.py --source "自行取得的RCSD工作簿完整路径"
python tools/verify_rcsd_handover.py --query-directory 02_few_shot_diagnosis/outputs/rcsd_optimization_v2
```

第一步校验文件，恢复344个原实验窗及压力场景，共520窗；不训练，也不假装完成未采用的增强试验。第二步用当前10算子和39资源比较13,728条冻结预测/评分，另查空表、错单位及重复时间。传感器数值只写入Git忽略目录。

## 重新训练

恢复输入后：

```text
python 02_few_shot_diagnosis/scripts/run_rcsd_seed_ensemble.py
python 02_few_shot_diagnosis/scripts/train_rcsd_rf.py
```

完成源期前推验证及原支持下的CNN/迁移/元学习单模型与集成。预期432行指标、38,016条预测、36份神经资源。默认 `outputs/rcsd_seed_ensemble_v2`，已存在则拒绝覆盖，可用 `--output-dir` 指定新目录。耗时依赖CPU，不是快速演示的必需步骤。

RF快速重训入口为 `train_rcsd_rf.py`：复用冻结原支持实现（强度列表为[1.0]），重训9种支持配置并比较36个条件指标，导出支持抽样11的3份模型并核对1,056条预测及评分，无需运行神经或失败增强试验。历史增强入口 `run_rcsd_optimization.py` 和 `run_rcsd_support_optimization.py` 不属于推荐部署链路，复现需另一个干净输出目录及完整前置步骤，不能把仅恢复输入当作已完成试验。

`run_rcsd_diagnosis.py` 保留普通原型、元学习原型、从头原型和RF筛选等对照。通用RF/CNN训练、源训练、适配入口为 `fit_process_resource.py`、`train_process_source.py`、`adapt_process_resource.py`，各自 `--help` 给出参数，不接收最终查询作为训练输入。

历史独立目录同环境重训已复现指标/预测，36份神经资源的全部张量/元数据一致。PyTorch在Windows中文/英文路径可能使用不同ZIP根目录，整文件SHA不一定相同；现成资源仍须按清单逐文件校验。复现不是新增效果证据。
