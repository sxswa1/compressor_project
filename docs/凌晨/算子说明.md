## 交付内容

10个UTF-8独立`.py`文件放在 [dataflow_operators](../../dataflow_operators/README.md)，并在同目录 `registry.py` 登记。9个实验链路算子加1个切窗辅助算子。每份源码包含完整第三方导入、辅助实现和唯一顶层 `execute(...)`；无需另交卡片JSON/YAML，平台负责生成卡片及实际入库。

入口明确接收 `df: pd.DataFrame` 和业务参数，保留 `**kwargs`，显式返回 `out_1/out_2` 两个DataFrame。模块加载不读模型或数据、不训练、不请求网络，推理由 `execute` 串联；源码文本执行不依赖 `__file__`。

## 数据链路

按设备、原始记录和既定划分分别处理：质量标记 → 有界补缺 → 时钟检查/对齐 → 连续切窗 → 诊断。默认只标记异常，不删除可能有意义的故障突变；无法补齐的窗口拒绝。对齐产生空行不等于补全成功。

统计特征用于RF及分析输出；CNN/元学习/迁移/集成直接使用多通道窗口，由资源中固定的归一化器处理，不能把统计特征表冒充原始测点窗口。

公共模块列名由调用者指定，不写死RCSD字段。MAD和居中滤波是离线方法。补缺在线模式须显式 `causal=True`、`method='ffill'`，有时钟时还须声明间隔。训练与查询分开调用，不共享质量统计量。

## 推理调用

```python
import json
from pathlib import Path
import pandas as pd

namespace = {"__name__": "dataflow_on_run"}
path = Path("dataflow_operators/fault_diagnosis/process_seed_ensemble.py")
exec(compile(path.read_text(encoding="utf-8"), "<on_run>", "exec"), namespace)

# 文件和模型路径由部署方提供，契约须描述数据真实物理含义。
df = pd.read_csv("actual_complete_windows.csv")
contract = json.loads(Path("actual_input_contract.json").read_text(encoding="utf-8"))
result = namespace["execute"](
    df=df,
    value_columns=[c["name"] for c in contract["channels"]],
    model_path="02_few_shot_diagnosis/resources/rcsd_v2/models/k5_meta_adapted_prototype_seed_ensemble.pt",
    input_contract=contract,
    window_id_column="window_id",
    time_column="timestamp",
)
predictions = result["out_1"]
model_information = result["out_2"]
```

| 参数 | 含义及约束 |
|---|---|
| df | 长表，一个窗口多行；每窗对应一个设备/原始记录/划分 |
| value_columns | 信号列名或列表；与契约和模型顺序一致 |
| model_path | 平台可访问的可信资源路径；不得写研发电脑绝对路径 |
| input_contract | signal_type、channels中name/unit/quantity/aggregation、interval_seconds、window_points |
| window_id_column | 默认window_id，不能为空，多窗可同表 |
| time_column | 默认timestamp；每窗连续唯一，乱序可排序，缺口和重复拒绝 |
| minimum_model_score | 默认None，可选[0,1]，阈值须验证；低于时输出unresolved |

`out_1`：窗口ID、start_time、end_time、predicted_label、model_score、diagnosis_status。`out_2`：资源类型、窗数及评分未校准说明；集成另有成员数和标签复用说明。空输入须有必需列且模型有效。

RCSD为25通道、15分钟、20点、4种受控状态。现场45测点/约6分钟不能直接套用。声学、高频波形与低频标量不互换。须确认字段、聚合、单位和标签后重新适配。归一化、权重和类别映射随模型保存，不能临时按查询拟合。

## 平台维护方接入

交接`.py`后，平台生成卡片并核对 `data_frame_input=["df"]`，业务参数名与签名一致。登记 `out_1/result_df/pd.DataFrame`、`out_2/info_df/pd.DataFrame`，均启用；不是按每列注册端口。

公共处理安装NumPy/Pandas；RF另装scikit-learn/joblib；神经另装PyTorch，版本见requirements。DSL和UDO环境可能不同，须安装在实际执行环境，并挂载模型到UDO可访问路径。

本地验证了源码文本加载和入口；**尚未操作真实平台数据库、生成平台卡片或在UDO服务执行**。仓库登记和GitHub上传不等于这些平台步骤完成。维护方须补做正常输入、空表、错误物理契约及模型挂载联调。
