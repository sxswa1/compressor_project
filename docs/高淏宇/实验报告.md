# 压缩机预警与风险量化：方法与结果


负责两项算法：**潜在故障超前预警、风险量化**。风险量化包括健康程度（DI）、四级风险和剩余寿命（RUL）。

使用 RCSD-1YD 公开离心压缩机数据，包含 25 个测点，每 15 分钟一条记录。在原始数据上做数据增强，加入不同速度和幅度的退化变化，并生成对应标签。下面的指标反映这套增强数据上的表现。

1—6 月用于训练，7—8 月用于开发验证，**实验结果均来自 9—12 月测试数据**。预警和 RUL 主实验使用 159 条完整退化轨迹，DI 使用 198 条场景。

|---|---|---|

## 主要方法对比

原方案是前期开发采用的方法，不代表对照实验中表现最好。各模块目前的比较结果如下。

| 模块 | 原方案结果 | 本次测试中表现更好的方法 |
|---|---|---|
| 预警 | 合并方案至少提前 2 小时的预警覆盖率 89.31%，原始运行告警占比 64.23% | EWMA 至少提前 2 小时的预警覆盖率 91.19%，告警占比 7.38%，两项均优于合并方案 |
| DI | Ridge 的 MAE 为 0.38288 | LSTM 平均 MAE 为 0.13812，是所测方法中最低，但不同随机种子间有波动 |
| 风险分级 | 按 Ridge 的 DI 分级，准确率 23.39% | 按 LSTM 的 DI 分级，平均准确率 53.89%，三次运行范围为 39.78%—75.68%，稳定性不足 |
| RUL | 背景处理＋追加增强＋梯度提升，RMSE 为 11.058 小时 | 相同处理下 ExtraTrees 平均 RMSE 为 10.824 小时，是所测方法中最低；与梯度提升的差异尚不明确 |

以上是同一批测试中的方法比较。最终选型需要结合验证集表现、多次运行稳定性和较难场景结果；按这批测试结果重新选择的方法，后续需要新的独立评价。

## 一、潜在故障超前预警

### 方法

使用 EWMA、CUSUM 和固定限值三种判断方式：

- **EWMA**：平滑观测偏离的变化，近期数据权重更大，判断是否持续异常。
- **CUSUM**：累积连续的小幅偏离，用于发现逐渐变化的异常。
- **固定限值**：测点超过设定限值时报警。

将三种判断合并输出告警，同时与单独使用 EWMA、CUSUM 的结果比较。

### 指标表现

| 方法 | 至少提前 2 小时的预警覆盖率（越高越好） | 原始运行告警占比 |
|---|---:|---:|
| 原合并方案 | 89.31%（142/159） | 64.23% |
| 单独 EWMA | **91.19%（145/159）** | **7.38%** |
| 单独 CUSUM | 91.82%（146/159） | 63.19% |

“至少提前 2 小时的预警覆盖率”指满足该提前量要求的有效预警轨迹数占全部完整退化轨迹数的比例。有效预警要求退化发生后产生新告警，并排除对应原样背景已经告警的情况。告警占比指原始运行有效时间点中有多少处于告警状态。若将这些数据视为正常背景，它就是该假设下的点级误报率；原始数据没有逐点确认的正常／异常标签。

**目前单独 EWMA 的至少提前 2 小时的预警覆盖率高于合并方案，持续告警也更少。** 合并方案告警偏多；在持续 288 小时、退化幅度减半的较难场景中，只检出 7/18，仍有漏检。

## 二、风险量化

### 1. 健康程度 DI

**原方案：** 从 25 个测点提取当前值、过去 6 小时和 24 小时的均值及首尾变化量，共 125 个特征，用 Ridge 回归预测 DI。DI 取值为 0—1，1 表示健康，0 表示设定的退化终点。

| 方法 | DI 平均绝对误差 MAE（越低越好） |
|---|---:|
| 原方案：历史特征＋Ridge | 0.38288 |
| 对照：始终输出训练标签的中位数 | 0.25706 |
| 对照：当前测点值＋ExtraTrees | 0.21728 |
| 对照：LSTM 时序模型 | **0.13812** |

MAE 先逐条场景计算，再取平均。0.38288 表示在 0—1 的 DI 范围内，平均绝对偏差约为 0.383，不能换算成准确率。树模型和 LSTM 报告三次不同随机种子运行的平均结果。

LSTM 使用连续观测窗口学习时间变化，再输出 DI。**本次测试中 LSTM 的平均误差最低；原 Ridge 方案效果较差，甚至不如固定值对照。** 它在 7—8 月的误差为 0.03817，到 9—12 月升至 0.38288，说明前期学到的关系没有适应后期数据。LSTM 误差较低，但三次运行的 MAE 在 0.09116—0.17733 之间，表现有波动。

### 2. 四级风险

**方法：** 根据预测的 DI 划分风险：I 级为 DI≥0.85，II 级为 0.65≤DI<0.85，III 级为 0.4≤DI<0.65，IV 级为 DI<0.4；等级越高，风险越高。

| 指标 | 原 Ridge 方案的结果 |
|---|---:|
| 分级准确率 | **23.39%** |
| 风险高估比例 | **76.61%** |
| I／II／III 级召回率 | 均为 0 |
| IV 级召回率 | 100% |

**原 Ridge 的分级效果较差。** DI 预测偏低，导致评价点都被判为最高风险，不能有效区分不同风险等级。

使用 LSTM 预测的 DI、按相同阈值分级，三次运行的准确率分别为 46.21%、39.78%、75.68%，平均 **53.89%**。比原 Ridge 更好，但波动较大，不能只报告最高的一次。

### 3. 剩余寿命 RUL

**原方案：** 先处理原始运行背景差异，再追加 360 条增强训练轨迹；提取当前值和历史统计特征，用梯度提升回归预测距离设定退化终点还有多少小时。

| 训练方案 | RUL 误差 RMSE（小时，越低越好） |
|---|---:|
| 基础方案：原测点＋原半合成训练集 | 11.793 |
| 仅增加背景处理 | 11.238 |
| 仅追加增强数据 | 11.160 |
| 背景处理＋追加增强（梯度提升） | 11.058 |
| 背景处理＋追加增强（ExtraTrees 对照） | **10.824** |

这里先计算每条轨迹的均方根误差，再取平均。该指标对较大的预测偏差更敏感，11.058 小时不代表每次预测都偏差这么多。

表中前四行使用梯度提升，最后一行使用 ExtraTrees（多棵随机树共同预测）。**ExtraTrees 在本次主实验中的平均误差最低。** 梯度提升组合相对其基础方案的误差降低约 6.24%；ExtraTrees 与该组合结果接近，尚不能确定谁稳定更好。在弱幅度、非线性和延迟叠加的较难场景中，梯度提升组合的误差为 15.647 小时，高于其基础方案的 14.072 小时。
