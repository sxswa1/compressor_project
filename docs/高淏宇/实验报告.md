# 预警与风险量化实验结果

高淏宇，2026-10-27

## 方法和主要结果

负责两个算法：超前预警、风险量化。风险量化包括 DI、四级风险和剩余寿命（RUL）。

使用 RCSD-1YD 的 25 个过程测点，采样间隔 15 分钟。在原始运行数据上进行数据增强，加入不同速度、幅度的退化轨迹，并生成对应的 DI 和 RUL 参考标签，形成半合成数据集。1—6 月用于训练，7—8 月用于开发比较，9—12 月用于测试。下面是 9—12 月结果。

| 模块 | 采用方法 | 指标表现 |
|---|---|---|
| 预警 | EWMA 累积变化检测 | 提前至少 2 小时检出 145/159 条轨迹，覆盖率 91.19%，漏警率 8.81% |
| DI | LSTM 根据历史窗口预测健康指数 | 平均绝对误差 0.13812，DI 范围为 0—1 |
| 四级风险 | 按 DI 固定阈值分级 | 准确率 53.89%，三个种子为 39.78%—75.68% |
| RUL | 处理运行背景差异，追加数据增强，训练 ExtraTrees | 轨迹平均 RMSE 10.824 小时；剩余 0—6 小时的轨迹平均 MAE 2.466 小时 |

预警的“提前”相对于构造的退化终点计算，并排除原始背景已经出现的告警。成功检出的提前期中位数为 20.75 小时。原始运行记录中，7.38% 的有效采样点处于告警状态；这是告警占比，原数据没有逐点故障标签，不能直接当作已确认的虚警率。

DI 和 ExtraTrees 指标均为三个种子的平均结果。数据增强提供了退化与寿命标签，这些结果对应构造退化条件下的算法表现。

## 为什么采用这些方法

预警方面，CUSUM 的覆盖率为 91.82%，但原始运行告警占比为 63.19%；EWMA 的覆盖率接近，告警占比降至 7.38%，因此采用 EWMA。

弱慢退化仍有漏检：在半幅、288 小时的补充场景中，EWMA 提前检出 6/18 条，覆盖率 33.33%。

DI 方面，新增配对一致性训练后，测试 MAE 从 0.13812 降至 0.13499，但风险准确率从 53.89% 降至 52.20%。考虑 DI 和风险分级的整体表现，继续采用原 LSTM。它在 7—8 月的风险准确率为 90.69%，后续月份下降明显，正常状态的 DI 低估和种子差异仍需改善。

RUL 方面，ExtraTrees 的轨迹平均 RMSE 在本次 11 种配置对照中最低；梯度提升在长寿命阶段更好，保留作主要对照。

| RUL 指标 | ExtraTrees（采用） | 梯度提升 |
|---|---:|---:|
| 轨迹平均 RMSE / 小时 | 10.824 | 11.058 |
| 总体 RMSE / 小时 | 12.908 | 10.998 |
| 总体 RMSE ÷ 平均参考 RUL | 48.54% | 41.36% |
| 剩余 0—6 小时：轨迹平均 MAE / 小时 | 2.466 | 2.728 |
| 剩余 >48 小时：逐点 MAE / 小时 | 26.404 | 17.018 |
| 退化终点：MAE / 小时 | 1.968 | 3.296 |

轨迹平均 RMSE 是先逐条计算再平均，总体 RMSE 是合并所有评价点计算。ExtraTrees 在短寿命和终点附近更准，但对超过 48 小时的剩余寿命低估明显。该段约占 15.25% 的评价点，贡献了 67.44% 的平方误差。梯度提升仅有一次运行记录，尚无种子间波动结果。

## 四级风险与 RUL 区间

风险划分为：正常Ⅰ级 DI≥0.85，注意Ⅱ级 0.65≤DI<0.85，警告Ⅲ级 0.40≤DI<0.65，危险Ⅳ级 DI<0.40。

| 预测风险等级 | RUL 总体 RMSE / 小时 | 区间覆盖率 | 区间平均宽度 / 小时 |
|---|---:|---:|---:|
| Ⅰ 正常 | 19.91 | 99.95% | 76.56 |
| Ⅱ 注意 | 17.60 | 99.97% | 72.70 |
| Ⅲ 警告 | 10.00 | 100.00% | 63.20 |
| Ⅳ 危险 | 4.39 | 100.00% | 49.95 |

每个有效预测点均输出风险等级和 RUL 区间。上表按预测等级统计，并非分别训练四套区间模型。汇总了三个种子的预测，Ⅰ级只有两个种子出现。区间覆盖率高，但宽度较大，暂时只能提供较宽的寿命范围。
