# 数据与接口

## 数据构建

原数据为 RCSD-1YD 离心压缩机过程记录，每 15 分钟采样一次，25 个测点。数据地址：https://doi.org/10.5281/zenodo.14866092 。

1—6 月训练，7—8 月开发验证，9—12 月测试。同一原始背景生成的场景保持在同一集合。主实验在温度、油压与温度、振动与轴位移三组测点上加入退化变化，持续 12、24、48、72 小时，包含三种变化曲线。

DI 从 1 下降到 0；完整轨迹的 RUL 为距构造终点的小时数。提前截断的轨迹保留 DI，不补造 RUL。RUL 另外使用 360 条完整增强轨迹，只进入训练部分。测点变化幅度由训练数据估计。

| 数据 | 主实验退化场景 | 其他场景 |
|---|---:|---|
| 训练 | 279 | 31 条原始背景回放 |
| 开发验证 | 99 | 11 条回放、165 条响应变化 |
| 测试 | 198 | 22 条回放、330 条响应变化、294 条压力测试 |

观测、标签、来源行号和注入掩码分表保存。模型只读取测点及时间；真实退化起点、终点、DI 和 RUL 不作为输入。多个场景共享原始背景，比较与重采样以背景分组。

配置见 `01_early_warning/experiments/rcsd_v1/RCSD-1YD Data Set/` 下两个数据版本的 `config.json`；正式测试规则见 `final_evaluation_protocol_v1/protocol.json`。

## 输入输出

`predict_research.py` 接收单设备 CSV，时间唯一、递增，采样间隔为 15 分钟。测点名称和顺序来自训练输出 `final_model_fit_v1/results/preprocessing.json`。温度为 ℃，压力为 kg/cm²，轴位移为 mm，振动为 μm，转速为 rpm。

| 输出 | 含义 |
|---|---|
| warning_active / warning_new | 当前告警状态／新告警事件 |
| DI / risk_level | 健康程度／I—IV 级风险 |
| RUL_hours | 剩余寿命点预测，小时 |
| RUL_lower_hours / RUL_upper_hours | 剩余寿命区间，小时；未校准该模型时为空 |
| di_valid / rul_valid / warning_valid | 对应输出是否具备有效历史 |

DI／RUL 使用 96 点窗口。预警需要当前点之前的 96 点历史。时间缺口和显式分段重新开始历史窗口；DI／RUL 还要求窗口内测点有限且转速在运行范围。无效输出保留为空，不能当作健康或零寿命。

## 指标

预警统计退化开始后的新事件，排除对应原样背景当前及前两点已有告警的情况。至少提前终点 2 小时算有效覆盖。完全漏检与提前不足 2 小时分别统计。原始运行告警占比按有效点计算。

DI 逐场景计算 MAE 再平均。RUL 逐场景计算 RMSE 再平均；总体 RMSE÷平均参考 RUL 另列。风险按 DI 的 0.85、0.65、0.40 阈值分为四级，边界归入较健康一级。RUL 区间使用训练期独立校准背景的最大绝对误差。

DataFlow 的预警与风险量化算子已放入 `dataflow_operators/health_assessment/`。两个文件各自包含完整推断逻辑，入口为 `execute(df, ...)`，均返回 `out_1` DataFrame。训练权重通过 `export_dataflow_models.py` 导出，再部署到实际执行环境；调用参数与示例见[研究目录](../../01_early_warning/README.md#dataflow-算子)。
