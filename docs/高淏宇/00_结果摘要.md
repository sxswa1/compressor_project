# 预警与风险量化结果

高淏宇，2026-10-27。

采用 EWMA 预警、LSTM DI 与四级风险、背景处理和追加增强后的 ExtraTrees RUL。

| 模块 | 9—12 月结果 |
|---|---|
| 预警 | 提前至少 2 小时检出 145/159 条，覆盖率 91.19%，漏警率 8.81% |
| 原始运行告警 | 有效点告警占比 7.38%；没有逐点故障标签，不能直接当作真实虚警率 |
| DI | 平均绝对误差 0.13812 |
| 四级风险 | 准确率 53.89%，种子范围 39.78%—75.68% |
| RUL | 轨迹平均 RMSE 10.824 小时，总体 RMSE 12.908 小时 |
| RUL 区间 | 每级风险均有输出；整体平均宽度 63.62 小时，覆盖率 99.99% |

实验基于 RCSD-1YD 数据增强得到的半合成退化轨迹。主要不足是弱慢退化漏检、正常段 DI 低估，以及长剩余寿命低估。梯度提升在长寿命段优于 ExtraTrees，完整对照见[实验报告](实验报告.md)和[结果表](实验结果表.xlsx)。
