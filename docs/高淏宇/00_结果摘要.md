# 方法与指标一览

高淏宇｜2026-10-25

负责潜在故障超前预警和风险量化两项算法。使用 RCSD-1YD 公开数据进行退化增强，实验结果来自 9—12 月测试数据。

## 项目原验收要求

来源：`压缩机项目分工.xlsx`，高淏宇负责部分的“验收要求”栏（Sheet1，F2）。

| 指标或功能 | 原验收要求 | 表现最佳方案的结果 |
|---|---|---|
| 预警提前期 | **≥2 小时** | **EWMA**：145/159 条轨迹满足至少提前 2 小时有效预警；有效检出轨迹的提前量中位数 **20.75 小时** |
| 系统虚警率 | **≤20%** | **EWMA：7.38%**，按原始有效运行数据作为正常背景计算的点级误报比例 |
| 漏警率 | **≤15%** | **EWMA：8.81%（14/159）**，按未产生有效配对预警的完整轨迹计算；另有 0 条提前量不足 2 小时 |
| 预警覆盖率 | **≥80%** | **EWMA：91.19%（145/159）**，采用至少提前 2 小时的有效预警条件 |
| RUL 预测误差 | **RMSE 不超过实际剩余寿命的 30%** | **ExtraTrees：48.54%**，按总体 RMSE÷平均参考剩余寿命计算，高于 30%；场景平均 RMSE 为 **10.824 小时** |
| RUL 区间输出 | 每级风险均输出对应的 RUL 预测区间 | **ExtraTrees** 已输出 RUL 预测区间，平均宽度 **63.62 小时**；现有统计尚未按四级风险分别列出 |
| 四级风险划分 | 正常（Ⅰ级）：DI 0.85～1.0；注意（Ⅱ级）：0.65～0.85；警告（Ⅲ级）：0.40～0.65；危险（Ⅳ级）：<0.40 | 已按上述阈值分为四级。**LSTM** 的平均分级准确率 **53.89%**，DI 平均绝对误差 **0.13812** |

预警列采用兼顾覆盖率和告警占比的 EWMA；DI／风险分级列采用平均表现较好的 LSTM；RUL 列采用场景平均 RMSE 最低的“背景处理＋追加增强＋ExtraTrees”。均为 9—12 月主实验结果，随机模型取三次运行均值。

分工表没有规定 DI 的 MAE 上限、风险分级准确率下限或 RUL 区间覆盖率要求。RUL 的“30%”未给出具体归一化公式；表中采用现有实验口径，总体 RMSE 为 12.908 小时，平均参考剩余寿命为 26.594 小时，与逐场景计算后平均的 10.824 小时口径不同。

## 本次实验结果

| 模块 | 本次测试的主要比较结果 | 仍存在的问题 |
|---|---|---|
| 超前预警 | **EWMA** 至少提前 2 小时的预警覆盖率 **91.19%（145/159）**，原始运行告警占比 **7.38%**。原合并方案分别为 89.31%、64.23%，两项均更差。 | 正常背景上仍有告警，弱慢退化仍有漏检。 |
| 健康程度 DI | **LSTM** 平均绝对误差 **0.13812**，是所测方法中最低；原 Ridge 为 0.38288，固定值对照为 0.25706。 | LSTM 三次运行误差在 0.09116—0.17733 之间，存在波动。 |
| 四级风险 | 按 **LSTM 的 DI** 分级，平均准确率 **53.89%**；原 Ridge 为 23.39%。 | LSTM 三次准确率为 46.21%、39.78%、75.68%，稳定性不足。 |
| 剩余寿命 RUL | **背景处理＋追加增强＋ExtraTrees** 平均 RMSE 为 **10.824 小时**，是所测方法中最低；相同处理下梯度提升为 11.058 小时。 | 两者差异尚不明确，还需结合较难场景结果判断。 |

原方案不等于最佳方案。表中列的是本次测试观察到的比较结果，最终选型需结合验证集表现和稳定性；按本次测试重新选型后，需要新的独立评价。

预警要求至少提前设定退化终点 2 小时检出。若将原始有效运行数据视为正常背景，告警占比就是该假设下的点级误报率。DI 和 RUL 的误差越低越好，随机模型报告三次运行均值。DI、寿命标签由增强规则生成。
