# 压缩机跨工况故障泛化诊断算法 —— 测试报告

> 任务：算法设计——压缩机跨工况故障泛化诊断技术（负责人：李佳耀）
> 验收指标：支持 ≥8 种压缩机典型故障模式识别，跨工况泛化故障诊断精度 ≥80%

## 1. 测试概述

| 项目 | 内容 |
|---|---|
| 被测对象 | 跨工况故障泛化诊断算法（`common_algorithms/` + `03_cross_condition/` + `dataflow_operators/`） |
| 测试数据 | CWRU 轴承公开数据集（10 类，4 工况） |
| 测试协议 | ① 留一工况（leave-one-out，验收指标）；② 源工况 {0,1,2} → 目标工况 {3}（多模型对比） |
| 测试环境 | Windows 11 / Python 3.11 / PyTorch 2.5.1 (CPU) |

## 2. 测试数据说明

- 工况（域）：4 种负荷 0/1/2/3 HP，对应转速 1797/1772/1750/1730 RPM。
- 故障类别（10 类）：正常 + 内圈/滚动体/外圈故障 × 0.007/0.014/0.021 in。
- 切片：窗长 1024 点、重叠率 0.5、逐样本 z-score 归一化。

## 3. 测试用例

| 用例 | 方法类别 | 说明 |
|---|---|---|
| TC-01 | 深度学习（无域自适应） | CNN / WDCNN / LSTM 源域训练，目标域直接测试 |
| TC-02 | 域自适应/域泛化 | DANN / DeepCORAL / DAN(MMD)，对齐源/目标分布 |
| TC-03 | 传统机器学习 | 随机森林 / 梯度提升（手工特征 + 物理机理特征） |
| TC-04 | 物理机理规则 | 阶次域故障特征频率占优判别 |
| TC-05 | 留一工况交叉验证 | 轮流留 1 个工况作测试，其余 3 个训练（验收协议） |
| TC-06 | 算子冒烟测试 | 7 个自包含算子 `execute()` 离线自检（特征/工况识别/诊断） |

>   表中为固定随机种子（seed=42）下的一次完整运行，原始输出见

## 5. 验收结论

| 验收指标 | 要求 | 实测结果 | 结论 |
|---|---|---|---|
| 故障类型数量 | ≥ 8 种 | 10 类（9 种故障 + 正常） | ✅ 通过 |
| 跨工况泛化精度 | ≥ 80% | 留一工况平均 **95.09%**（四目标 96.12/93.75/99.91/90.58%）；源→目标协议 DANN 99.75%、DAN-MMD 99.79%、DeepCORAL 99.58%、WDCNN 95.65%、梯度提升 94.47%、CNN 93.24%、LSTM 93.12%、随机森林 92.87% | ✅ 通过 |
| 多模型 + 模型切换 | 需多种模型并可切换 | 16 个深度学习模型名 + 随机森林/梯度提升/物理规则，`create_model` 按名切换 | ✅ 通过 |

**结论：满足全部验收指标。** 留一工况协议下平均准确率 95.09%，四个目标工况均 ≥ 90%；
域自适应方法（DANN/DeepCORAL/DAN）目标工况精度均达 99% 以上，传统机器学习基线达
92% 以上，普通 CNN 亦超过 80% 线，跨工况泛化能力达标。
